# Statement-coverage floors for core, one per package.

# A floor is what the package reached when it was last touched, rounded down to a
# whole percent so ordinary churn does not force an edit. It may only go up: a
# drop fails `make cover-check`, and lowering a number is a claim the reviewer of
# the pull request has to accept.
#
# "-" marks a package with no floor. The conformance suites are executed by the
# modules that own an implementation, not by core, so a core-only profile reports
# nothing for them and a floor there would be a claim nobody made.
